## NinjaArm
NinjaArm is a custom robotic arm with 3 degrees of freedom + a claw. It uses an Arduino Uno along with a servo board, 3 servos, 1 micro servo, and 4 potentiometers to control rotation. It includes a small stand for the potentiometers, and a larger display stand to hold the servo board and Arduino. I decided to create a robotic arm beacuse after building a working keyboard in real life I wanted a larger and more ambitious project. I thought that robotic arms seemed cool, so I decided to create my own from scratch.
